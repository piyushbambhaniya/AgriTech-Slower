# 🌾 KisaanSmart
### AI Crop Advisory & Market Price Tool for Indian Farmers

> Built for **MyBharat Hack Social 2024** | Theme: AgriTech

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://kisaansmart.streamlit.app)

---

## 🚀 Features

| Feature | Description |
|---|---|
| 🌱 Crop Advisory | Sowing tips, fertilizer, diseases for 7+ crops |
| 💰 Mandi Prices | Live wholesale prices at 5 major markets |
| ☀️ Weather | Real-time weather + farming recommendations |
| 🏛️ Govt Schemes | PM-KISAN, PMFBY, KCC, eNAM and more |
| 🤖 AI Chatbot | Ask questions in Hindi or English |

## 📸 Screenshots

## 🛠️ Tech Stack

- **Python 3.10+**
- **Streamlit** — Web framework
- **Pandas** — Data handling
- **No external API keys needed** — Works offline!

---

## ▶️ Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/kisaansmart.git
cd kisaansmart

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the app
streamlit run app.py
```

App will open at **http://localhost:8501**
